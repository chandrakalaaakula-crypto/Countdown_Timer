# ⏳ Countdown Timer Using Python

 Overview
The Countdown Timer is a simple GUI-based application developed using Python and Tkinter. It allows users to enter a time duration in seconds and displays a countdown in HH:MM:SS format. When the timer reaches zero, a notification message appears.

## ✨ Features
- Enter countdown time in seconds.
- Start the countdown timer.
- Pause the timer at any moment.
- Reset the timer.
- Display time in HH:MM:SS format.
- Show a notification when the countdown finishes.
- Simple and user-friendly graphical interface.
